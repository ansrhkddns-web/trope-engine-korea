# Acceptance Tests

Use this file when the user asks whether a generated trope engine is "good enough", "commercial enough", "ready", or "needs more work".

## Test Levels

### 10-Second Test

The concept passes if a reader can understand within 10 seconds:

- genre;
- protagonist's unfair advantage;
- expected reward;
- why the first scene is fun.

Fail signs:

- proper nouns dominate;
- reward is abstract;
- protagonist's method is unclear.

### First-Scene Test

The first scene passes if it includes:

- pressure;
- protagonist action;
- proof object;
- witness;
- visible reward;
- new pressure.

Fail signs:

- mostly explanation;
- private power-up only;
- no one reacts;
- the hook appears before payoff.

### Five-Episode Test

The first five episodes pass if they prove repeatability:

| Episode | Required job |
| --- | --- |
| 1 | prove title promise |
| 2 | repeat method with variation |
| 3 | add institution or social proof |
| 4 | reveal cost or stronger opponent |
| 5 | pay first mini-arc and open larger pressure |

Fail signs:

- episodes 2-5 repeat the same reversal;
- no institution reacts;
- the protagonist wins without cost.

### Paid-Trust Test

The paid boundary passes if:

- free ending creates a concrete question;
- first paid episode pays one promised reward quickly;
- a larger pressure opens after payoff;
- readers do not feel the answer was merely withheld.

Fail signs:

- pure cliffhanger with no payoff;
- paid episode starts with unrelated setup;
- reward debt piles up.

### 50-Episode Test

The engine passes if it can scale:

- personal enemy;
- local institution;
- major organization;
- public/national layer;
- hidden world/system/heavenly engine.

Fail signs:

- new villains are unrelated;
- scale increases but reward type changes;
- mystery replaces payoff.

### Originality Test

The concept passes if:

- it uses generic genre grammar;
- named references are not required to understand it;
- institution, proof object, scene order, and consequence differ from any reference;
- copied terms or signature scenes are absent.

Fail signs:

- title/logline depends on a known work;
- opening sequence mirrors a reference;
- unique rule systems remain recognizable.

## Verdict Rules

- `pass`: all critical tests pass or need only small wording changes.
- `revise`: one or two tests are weak but the core engine works.
- `rebuild`: 10-second, first-scene, or originality test fails badly.
