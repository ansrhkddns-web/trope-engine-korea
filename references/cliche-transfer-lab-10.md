# Cliche Transfer Lab 10

Use this file with `trope-memory-distiller-10.md` when a saved cliche memory must be adapted into another Korean webnovel genre without losing the familiar reader reward.

Phase 10 treats transfer as a controlled operation. The goal is not "mix genres." The goal is to preserve the protected core of a cliche while changing the shell enough to fit a new genre, institution, proof object, and episode rhythm.

## Transfer Principles

| Principle | Meaning |
| --- | --- |
| preserve reward first | readers must still know what pleasure they are buying |
| translate institution | every genre needs a believable authority that can react |
| translate proof object | proof must be visible in the target genre's language |
| translate cost | success must create a target-genre consequence |
| keep method active | the protagonist must choose and act, not merely receive luck |
| preserve cadence | free/paid rhythm and reward debt must still work |
| break copy-shadow | source scene order, names, and rule systems must not survive |

## Transfer Procedure

1. **Select memory**: choose one memory card by retrieval cues.
2. **Name protected core**: state the reward, pressure, method, proof, witness, cost, and hook that cannot disappear.
3. **Choose target genre**: assign the new genre shell and first-click owner.
4. **Translate institution**: choose who has authority to recognize or punish the proof.
5. **Translate proof object**: choose the target-genre evidence readers can see.
6. **Translate cost**: make the new problem arise from the success.
7. **Translate hook**: choose a target-genre object that opens the next question.
8. **Check rhythm**: confirm first proof, 1-5 loop, paid boundary, and 50+ ladder.
9. **Run anti-copy test**: remove source-specific names, rules, scene order, and unique mechanics.
10. **Write target card**: produce a ready-to-use cliche card or episode seed.

## Transfer Operators

| Operator | Use when | Example shape |
| --- | --- | --- |
| institution swap | source authority does not fit target genre | stock exchange -> hunter association |
| proof translation | proof object is genre-specific | market chart -> raid survival ledger |
| cost migration | source consequence feels random after transfer | shareholder lawsuit -> guild monopoly lawsuit |
| witness escalation | target genre needs stronger social proof | professor -> imperial examiner |
| reward re-skin | same pleasure needs local vocabulary | rank -> sect standing -> family succession |
| hook object swap | cliffhanger object must fit genre | takeover notice -> duel letter |
| cadence compression | target format needs faster payoff | 5-step proof -> 2-episode proof/payoff |
| shell inversion | trope feels stale in target genre | public test becomes secret audit, then public reveal |

## Transfer Risk Matrix

| Risk | Sign | Repair |
| --- | --- | --- |
| reward drift | transferred card now pays a different pleasure | rewrite proof and witness around original reward |
| shell-only transfer | only terms changed | rebuild pressure, proof, cost, and institution |
| copy-shadow | source scene order remains recognizable | change institution, timing, consequence, and witness |
| weak target witness | authority reaction does not matter | choose witness who controls access/status |
| private proof | reader sees power but world does not react | add public metric or authoritative record |
| cost mismatch | consequence does not arise from success | connect cost to proof visibility |
| cadence break | transfer opens too many hooks before payoff | pay one reward before new pressure |

## Transfer Verdict

| Verdict | Use when |
| --- | --- |
| pass | reward, proof, witness, cost, and hook all fit the target genre |
| revise | one or two translated axes are weak but core reward survives |
| rebuild | reward drift, copy-shadow, or no target-genre proof |
