# External Cliche Reference Map

Use this file when the user asks to upgrade the trope engine with broader cliche references, or when a generated pack needs more structural variety than Korean webnovel defaults alone.

This file does not copy external trope pages or named examples. It extracts reusable classification principles from public trope, motif, folklore, and story-ideation references.

## Core Distinctions

### Trope vs Cliche vs Motif

- **Trope**: a recognizable storytelling convention or device.
- **Cliche**: a familiar device that risks feeling stale if it has no fresh proof, cost, or witness.
- **Motif**: a smaller reusable element such as a forbidden door, token, contract, test, false hero, hidden helper, special object, or prophecy.
- **Premise engine**: a larger repeated structure that can sustain many episodes.

When designing, do not ask "Is this original?" first. Ask:

1. What function does this familiar device perform?
2. What reader reward does it pay?
3. What proof object makes it visible?
4. What witness or institution reacts?
5. What cost renews the loop?

## Extraction Rules

When consulting any cliche reference:

1. Extract the **function**, not the name.
2. Extract the **reader-recognition signal**, not a signature scene.
3. Extract the **pressure relationship**, not the exact plot.
4. Extract the **motif unit**, not the proprietary setting.
5. Rebuild using Korean webnovel institutions: association, guild, tower, system, constellation, chaebol family, board, sect, academy, market, court, media.
6. Add a visible proof scene and cost.

## Source Notes

These sources are useful as orientation points:

- TV Tropes pages such as Narrative Devices and Narrative Tropes organize recurring story devices and conventions.
- Library guides on ATU and motif indexes describe tale types and motifs as tools for comparing narrative patterns across traditions.
- Propp's morphology provides a function-sequence view of recurring plot events.
- Polti's dramatic situations provide conflict-pressure categories.
- Recent story-ideation papers such as TropeTwist and TaleStream treat tropes as abstract, connectable story units.

Use sources as maps, not as material to copy.
