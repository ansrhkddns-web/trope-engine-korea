# Reader Reward Model

Use this file when a trope pack needs stronger commercial pull, reward cadence, paid trust, or reader-retention logic. A trope is useful only when it reliably pays a reader reward.

## Reward Channels

Choose 2-4 dominant channels for a concept. Do not try to maximize all of them at once.

| Reward | Reader pleasure | Visible proof |
| --- | --- | --- |
| Power | The protagonist can now do what was impossible. | skill, realm, damage result, rescue, enemy defeat |
| Status | Others must recognize the protagonist differently. | rank board, contract, title, family seat, sect token |
| Money | The protagonist turns knowledge/action into assets. | cash, shares, land deed, acquisition, auction bid |
| Revenge | A past wrong is answered with consequence. | exposure, loss of rank, public apology, legal defeat |
| Knowledge | The protagonist understands the world better. | hidden condition, prediction, decoded rule, solved mystery |
| Safety | Someone survives because of the protagonist. | rescued civilians, cured ally, protected base, avoided disaster |
| Relationship | Trust, loyalty, fear, dependence, or affection changes. | recruit, oath, debt, confession, alliance, betrayal shift |
| Autonomy | The protagonist escapes control. | refuses contract, leaves family, breaks system rule, wins choice |
| Public reaction | The fun is amplified by witnesses. | crowd silence, comments, news, guild panic, elder recognition |

## Reward Cadence

Use cadence to prevent the story from becoming all setup.

- **Opening screen**: show the genre promise before explaining the world.
- **Episode 1**: give one small but concrete reward and one sharper next-click question.
- **Episodes 2-5**: prove repeatability. The reader must see that the fun can happen again.
- **Episodes 6-10**: add cost, rival, institution response, or first larger reward.
- **Episodes 11-25**: turn early wins into a visible ladder: rank, money, faction, team, territory, or reputation.
- **Free-to-paid boundary**: never use pure withholding. Pay one promise, then open the next larger pressure.
- **Episodes 26-50**: expand the arena without changing the core pleasure.
- **After 50**: rotate rewards: major payoff, new cost, social proof, larger arena, mystery recovery.

## Reward Ledger

Track each major promise:

| Promise opened | Reward type | Payoff evidence | Witness | Deadline | Debt risk |

|  |  |  |  |  |  |

Rules:

- Every hook that withholds an answer creates reward debt.
- Pay small debts quickly and large debts on visible arc milestones.
- If the protagonist gains power privately, add public proof soon.
- If revenge is delayed, give progress markers: evidence, ally, leverage, public suspicion, legal foothold.
- If money is promised, show ownership and consequence, not only numbers.
- If knowledge is promised, make the knowledge change a decision.

## Reward Pairings

Strong commercial packs often pair one internal reward with one external proof:

- **Power + public reaction**: hidden ability becomes social proof.
- **Money + revenge**: asset gain hurts the person who dismissed the protagonist.
- **Knowledge + rescue**: future information saves people and earns trust.
- **Status + autonomy**: a rank/title lets the protagonist refuse control.
- **Relationship + power**: an ally believes because the protagonist proves value.
- **Revenge + moral safety**: punishment feels deserved because the harm is visible.

## Common Reward Failures

- **Private-only reward**: the protagonist gets a skill, but no one reacts and no scene changes.
- **Delayed-first-reward**: the story asks readers to wait through worldbuilding before fun appears.
- **Reward inflation**: each win is bigger, but not more meaningful.
- **Unpaid hook debt**: mysteries pile up and readers stop trusting promises.
- **Numbers without consequence**: stats, money, or ranks change with no new access or enemy response.
- **Revenge without proof**: villains are punished before readers feel the wrong clearly.

## Repair Moves

- Add a witness to the reward.
- Add an object that proves the reward: contract, ranking, deed, scar, token, title, item, message.
- Pay a smaller promise before opening a larger one.
- Turn a private insight into a public choice.
- Connect every reward to the next problem: rank creates attention, money creates suspicion, rescue creates debt, revenge creates counterattack.
