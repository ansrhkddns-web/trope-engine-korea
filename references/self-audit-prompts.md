# Self-Audit Prompts

Use this file before finalizing substantial outputs or when the user asks to improve quality. These prompts are not for the user; they are internal checks to revise the answer before presenting it.

## Universal Audit

Ask:

1. Did I name the primary reader promise in one sentence?
2. Did I choose one primary genre engine?
3. Did I explain the protagonist's active method, not only their special trait?
4. Did I include a first proof scene?
5. Does the first proof scene have pressure, action, proof object, witness, reward, and cost?
6. Did every selected cliche card have a job?
7. Did every major reward have visible proof?
8. Did I include at least one freshness lever that changes a scene?
9. Did I avoid copying named settings or signature scene sequences?
10. Did I tell the user the next concrete step?

If two or more answers are weak, revise before finalizing.

## Trope Pack Audit

Check:

- Are there 3-7 cliche cards for quick pack or 8-15 for full concept?
- Does each card pay a different or clearly staged reward?
- Are cards ordered by use, not random list?
- Is there one cliche that proves the engine in episode 1?
- Is there one cliche that creates long-term escalation?
- Are stale cards marked as restricted or risky?

Repair:

- Cut excess cards.
- Assign each card to first proof, reward loop, escalation, social proof, or hook.
- Replace duplicate-card functions.

## Freshness Audit

Check:

- What familiar pleasure is preserved?
- What exactly changed: institution, proof object, witness, cost, timing, moral frame, or arena?
- Is the new element visible in a scene?
- Does the newness create pressure instead of lore?
- Would a reader still recognize the genre within the first scene?

Repair:

- Restore the expected reward.
- Change only one or two variation axes.
- Add a proof object and witness.

## Package Audit

Check:

- Does the title promise match the logline?
- Do the tags match the first 5 episodes?
- Does episode 1 prove the title promise?
- Does the first paid turn pay something before withholding more?
- Is the intro understandable without a lore glossary?

Repair:

- Rewrite title around the actual reward.
- Move the proof scene earlier.
- Remove tags that are not supported by early episodes.

## Diagnosis Audit

Check:

- Did I lead with the judgment: pass, revise, or rebuild?
- Did I name the biggest cause of reader drop-off?
- Did I preserve a useful strength?
- Did I give exact repair actions?
- Did I rewrite the weak first proof or reward loop?

Repair:

- Replace abstract critique with a work order.
- Add a revised example scene or episode function.

## Long-Form Engine Audit

Check:

- Is the 1-5 episode path clear?
- Does 6-25 add institutional reaction?
- Does 26-50 expand the arena without changing the promise?
- Does each scale jump have a public proof?
- Does the enemy ladder connect logically?

Repair:

- Tie each new enemy to the previous reward.
- Add institution reaction after each major win.
- Preserve the same reader reward at larger scale.

## Originality Audit

Check:

- Could the pitch stand without naming the reference work?
- Are names, terms, institutions, and rule wording distinct?
- Did I change the first proof scene?
- Did I change proof object, witness, cost, and consequence?
- Are only broad genre functions reused?

Repair:

- Abstract the desired pleasure.
- Rebuild from a generic trope function.
- Change institution and proof object first.

## Compact Final Audit Line

Before finalizing, silently complete:

`The output is ready because the reader promise is __, the protagonist proves it by __, the visible reward is __, the witness is __, and the next pressure is __.`

If any blank is weak, revise.
