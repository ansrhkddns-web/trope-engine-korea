# Default Genre Settings

Use this file to choose the default values that make a Korean webnovel genre feel immediately recognizable. Treat these as starting values, not laws. Change them only after preserving the reader reward.

## Index

- `Universal Setting Axes`: the fields every genre profile should define.
- `Hunter Association / Gate / Raid`: association, gate, dungeon, guild, loot, raid grammar.
- `Tower / System / Status Window / Constellation`: floors, quests, titles, sponsors, hidden rules.
- `Regression / Future Knowledge / Information Advantage`: future events, early assets, recruitment, altered history.
- `Chaebol / Stocks / Real Estate / Corporate Acquisition`: family hierarchy, boardroom, markets, M&A.
- `Martial Arts / Sect / Demonic Cult / Orthodox Factions / Fortuitous Encounter`: sect hierarchy, duels, manuals, qi, faction conflict.
- `Academy / Ranking / Training Institution`: tests, rivals, teams, sponsors, school ranks.
- `Possession / Reincarnation / Extra / Villain Role`: death flags, plot knowledge, route disruption.
- `Production / Support Class / Crafting`: undervalued support roles that become strategic value.
- `Revenge / Punishment / Evidence`: wrongdoing, proof, exposure, legal/social consequence.
- `Genre Blend Defaults`: common cross-genre default combinations.

## Universal Setting Axes

Every genre pack should define:

- **Reader promise**: what pleasure the reader expects every few episodes.
- **World engine**: the rule that repeatedly creates problems.
- **Status ladder**: how the protagonist rises in rank, money, authority, power, fame, or fear.
- **Advantage**: what the protagonist knows, owns, sees, remembers, or can exploit.
- **Institution**: the group that measures and reacts to value.
- **First proof**: the first scene that proves the concept.
- **Repeatable reward**: the reward that can happen again and again.
- **Expansion path**: how the story grows past the first arc.
- **Freshness lever**: the axis most worth changing.

## Hunter Association / Gate / Raid

- **Reader promise**: weak-looking protagonist proves value through raids, ranks, loot, survival, and public recognition.
- **World engine**: gates/dungeons appear with rank, rules, monsters, byproducts, and disaster risk.
- **Status ladder**: civilian -> awakener -> low-rank hunter -> guild asset -> raid leader -> national ranker -> strategic resource.
- **Advantage**: hidden skill, abnormal growth, regression knowledge, monster pattern reading, gate rule interpretation, production/crafting talent, legal loophole.
- **Institution**: hunter association, guilds, raid brokers, insurance companies, media, government disaster office, item market.
- **First proof**: rank test error, emergency gate break, low-grade raid with hidden boss, rescue scene, impossible drop item, public measurement mismatch.
- **Repeatable reward**: rank up, rare loot, skill evolution, guild reaction, market price jump, citizen rescue, enemy humiliation.
- **Expansion path**: local gates -> guild politics -> disaster zones -> international raids -> origin of gates -> system/constellation layer.
- **Freshness levers**: make the association an insurer, ratings agency, labor union, court, disaster bureaucracy, or securities market; make gates affect real estate, logistics, patents, agriculture, medicine, or politics.
- **Common risks**: too many stat windows; passive protagonist waiting for gates; rank inflation with no social consequence.

## Tower / System / Status Window / Constellation

- **Reader promise**: the protagonist understands rules better than everyone and turns impossible tests into rewards.
- **World engine**: floors, quests, penalties, sponsors, hidden conditions, rankings, messages, livestream-like observation.
- **Status ladder**: challenger -> floor clearer -> hidden-title holder -> sponsor candidate -> ranker -> rule-breaker -> system negotiator.
- **Advantage**: regression memory, guidebook knowledge, unreadable trait, sponsor immunity, ability to see hidden conditions, ability to trade with the system.
- **Institution**: tower administrators, constellations, sponsors, rankers, clans, floor markets, tutorial authority.
- **First proof**: tutorial reward exploit, impossible quest clear, hidden title acquisition, sponsor interest, ranking board anomaly.
- **Repeatable reward**: title, skill, item, sponsor favor, floor privilege, new rule access, public ranking shock.
- **Expansion path**: tutorial -> early floors -> sponsor war -> administrator conflict -> origin of system -> outside-world consequence.
- **Freshness levers**: sponsor economy, contract law, streaming reactions, religious politics, tax/tribute rules, floor-specific civilizations, system bugs as legal precedents.
- **Common risks**: system becomes vending machine; constellations comment without plot effect; rewards feel abstract.

## Regression / Future Knowledge / Information Advantage

- **Reader promise**: the protagonist wins early because they remember what others do not.
- **World engine**: known disasters, future villains, undervalued assets, hidden talents, doomed relationships, market turns.
- **Status ladder**: ruined survivor -> early mover -> asset collector -> hidden-network builder -> future controller -> history changer.
- **Advantage**: memory of events, names, prices, betrayals, dungeon rules, medical breakthroughs, scandals, mergers, wars, or apocalypse dates.
- **Institution**: markets, guilds, families, governments, schools, sects, media, courts, secret organizations.
- **First proof**: buys worthless asset before surge, prevents known disaster, recruits future talent, exposes future traitor, clears hidden condition first.
- **Repeatable reward**: arbitrage profit, future boss preemption, loyalty from rescued people, public "impossible prediction" reaction.
- **Expansion path**: personal recovery -> asset accumulation -> network control -> national crisis -> change in fate/system.
- **Freshness levers**: memory has gaps, future changes because of action, knowledge requires capital, each intervention creates a new cost, protagonist must create the future rather than merely harvest it.
- **Common risks**: protagonist only explains; no suspense because they know everything; gains feel unearned.

## Chaebol / Stocks / Real Estate / Corporate Acquisition

- **Reader promise**: money, family hierarchy, market information, revenge, and public status reversal.
- **World engine**: inheritance, board votes, hostile takeovers, land development, crisis investing, scandals, contracts, patents, political ties.
- **Status ladder**: ignored child/outsider -> small investor -> division owner -> board player -> conglomerate heir -> national economic actor.
- **Advantage**: regression memory, hidden documents, technical expertise, future market knowledge, family weakness, legal leverage, M&A timing.
- **Institution**: chaebol family, board, prosecutors, banks, media, shareholders, land office, startup ecosystem, foreign funds.
- **First proof**: wins a tiny but decisive deal, buys land before announcement, predicts stock crash, saves a subsidiary, flips a boardroom insult.
- **Repeatable reward**: profit, shares, land, voting power, media headline, family humiliation, acquisition, alliance.
- **Expansion path**: family conflict -> subsidiaries -> national markets -> global capital -> political/economic order.
- **Freshness levers**: combine with gates as new commodities, hunter guild IPOs, tower item futures, sect-owned corporations, ESG/disaster insurance, patent wars, logistics monopolies.
- **Common risks**: numbers without drama; effortless profit; villains who only shout; finance scenes with no visible consequence.

## Martial Arts / Sect / Demonic Cult / Orthodox Factions / Fortuitous Encounter

- **Reader promise**: martial growth, hierarchy reversal, secret manuals, duels, sect politics, righteous hypocrisy, demonic charisma, revenge.
- **World engine**: martial realm stages, sect rules, honor debts, tournaments, forbidden manuals, relics, poison, bloodline, teacher-student ties.
- **Status ladder**: cripple/outer disciple -> promising disciple -> sect representative -> rising master -> faction pivot -> transcendent figure.
- **Advantage**: reincarnation/regression, lost manual interpretation, modern tactical thinking, demonic technique, hidden constitution, poison immunity, merchant/information network.
- **Institution**: orthodox alliance, demonic cult, clans, merchant guilds, imperial court, martial academy, hidden elders, medicine halls.
- **First proof**: impossible test pass, broken meridian workaround, duel upset, manual reinterpretation, poison reversal, elder recognition.
- **Repeatable reward**: realm breakthrough, technique upgrade, public duel victory, disciple recruitment, debt repayment, sect rank, enemy fear.
- **Expansion path**: sect survival -> regional faction war -> orthodox/demonic conflict -> imperial/heavenly order -> origin of martial law.
- **Freshness levers**: make "qi" interact with contracts, finance, modern logistics, gate systems, forensic medicine, media rumors, or religious bureaucracy.
- **Common risks**: training without conflict; realm names with no felt difference; orthodox/demonic labels without institutional behavior.

## Academy / Ranking / Training Institution

- **Reader promise**: tests, rankings, rivals, teachers, clubs, teams, hidden talent, social hierarchy reversal.
- **World engine**: exams, practical tests, tournament brackets, dorm factions, sponsorship, school rules, academy secrets.
- **Status ladder**: bottom student -> class anomaly -> team leader -> school representative -> league champion -> institutional reformer.
- **Advantage**: regression, hidden trait, monster knowledge, future exam answers, unusual mentor, crafting/support ability, rule loophole.
- **Institution**: academy, student council, faculty, sponsors, guild recruiters, ranking board, noble/chaebol families.
- **First proof**: entrance test twist, team assignment upset, practical exam exploit, teacher notices abnormal answer.
- **Repeatable reward**: ranking rise, rival reaction, teacher support, team loyalty, sponsor offer, tournament win.
- **Expansion path**: class tests -> school tournament -> inter-academy contest -> field mission -> institutional conspiracy.
- **Freshness levers**: combine academy with hunter insurance, corporate recruitment, tower floor schools, sect exams, celebrity/media survival.
- **Common risks**: school life stalls the main genre; tests lack stakes; too many rivals with same function.

## Possession / Reincarnation / Extra / Villain Role

- **Reader promise**: the protagonist knows the story role, avoids death flags, steals opportunities, changes relationships, and converts a doomed script.
- **World engine**: original plot events, character routes, death flags, villain accusations, family/school/social scripts.
- **Status ladder**: doomed extra/villain -> survival planner -> hidden helper -> plot disruptor -> new protagonist of history.
- **Advantage**: original story knowledge, character psychology, hidden item locations, event timing, meta-genre literacy, changed personality.
- **Institution**: noble family, academy, guild, sect, entertainment agency, corporation, game system, original protagonist party.
- **First proof**: dodges a death flag, refuses expected humiliation scene, takes hidden reward, exposes original villain's trick.
- **Repeatable reward**: survival, favorability shift, route control, hidden reward, public reputation repair, fate reversal.
- **Expansion path**: avoid death -> take agency -> change core relationships -> rewrite main plot -> confront world/story system.
- **Freshness levers**: make the original story unreliable, make "good choices" costly, let other characters remember fragments, make the role itself valuable.
- **Common risks**: protagonist over-explains canon; original protagonist becomes flat; no stakes after death flag is avoided.

## Production / Support Class / Crafting

- **Reader promise**: a dismissed non-combat role becomes indispensable through crafting, healing, appraisal, logistics, medicine, cooking, engineering, or support strategy.
- **World engine**: combat society undervalues support until survival rate, item quality, medicine, patents, supply routes, or hidden appraisal changes outcomes.
- **Status ladder**: disposable porter/support -> useful specialist -> team core -> guild/sect asset -> market maker -> strategic monopoly.
- **Advantage**: abnormal appraisal, regression recipes, hidden material knowledge, system crafting tree, medicine insight, monster ecology, logistics optimization.
- **Institution**: guild logistics office, item market, medicine hall, patent office, hunter association, sect resource hall, academy lab, corporate R&D center.
- **First proof**: failed raid survives because of preparation, worthless material becomes rare item, incurable wound is stabilized, item appraisal flips auction value.
- **Repeatable reward**: money, team dependence, rescue, patent/item rights, public recognition, enemy underestimation reversal.
- **Expansion path**: team survival -> guild dependence -> market monopoly -> institutional regulation -> national/sect-wide supply war.
- **Freshness levers**: make support value measurable through insurance, survival data, patent rights, sect medicine routes, tower floor logistics, or disaster evacuation.
- **Common risks**: support class becomes generic combat god too quickly; crafting scenes become recipe lists; rewards lack witnesses.

## Revenge / Punishment / Evidence

- **Reader promise**: the protagonist answers betrayal, humiliation, exploitation, or false accusation with visible, deserved consequence.
- **World engine**: enemies hold social power through family, guild, sect, school, board, media, law, contract, or public reputation.
- **Status ladder**: victim/suspect -> evidence holder -> leverage builder -> public challenger -> institutional punisher -> system/family/faction reformer.
- **Advantage**: regression knowledge, documents, witness rescue, hidden recordings, market leverage, legal loophole, poison/technique proof, future scandal timing.
- **Institution**: court, board, guild hearing, sect trial, association audit, media, shareholder meeting, academy discipline office, imperial court.
- **First proof**: protagonist turns a trap into evidence, exposes a small lie, protects a witness, or wins one public procedural point.
- **Repeatable reward**: exposure, loss of enemy rank/assets/face, apology, legal defeat, ally liberation, public opinion shift.
- **Expansion path**: personal enemy -> enabling institution -> hidden patron -> public system -> root cause.
- **Freshness levers**: punish through contracts, audits, inheritance clauses, guild licenses, duel law, medicine records, market disclosure, or sponsor reputation.
- **Common risks**: revenge delayed without progress; enemies are evil but not proven; punishment happens privately; protagonist becomes passive while gathering evidence.

## Genre Blend Defaults

- **Hunter + Finance**: gates create commodities, guild IPOs, dungeon land rights, disaster insurance, item futures, M&A of raid companies.
- **Regression + Chaebol**: future knowledge becomes capital, but family politics and legal proof create friction.
- **Tower + Constellation + Streaming**: sponsors behave like patrons, investors, fandoms, gods, or algorithmic audiences.
- **Martial Arts + System**: status windows quantify martial realms, but old masters and sect law resist the new measurement.
- **Academy + Hunter**: school tests feed guild recruitment, public rankings, and early dungeon access.
- **Possession + Martial Arts**: doomed side character uses plot knowledge to hijack manuals, debts, and faction alliances.
- **Chaebol + Gate**: land value, logistics, medical patents, guild ownership, and disaster response turn fantasy rewards into corporate battles.
- **Regression + Apocalypse**: early accumulation must pay off through rescue, base building, and trust, not only hoarding.
- **Hunter + Support Class**: undervalued support changes survival rates, insurance values, guild recruitment, and item markets.
- **Martial Arts + Evidence Revenge**: sect hypocrisy is punished through duel law, poison proof, medicine records, or honor debt.
- **Chaebol + Revenge**: family abuse becomes boardroom leverage, public disclosure, shareholder revolt, or legal punishment.
