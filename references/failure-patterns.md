# Failure Patterns

Use this file when a generated trope pack feels busy, generic, too smooth, too derivative, or hard to serialize.

## Common Failure Patterns

### Keyword Soup

- **Symptom**: hunter, tower, regression, chaebol, academy, constellation, and martial arts all appear at once.
- **Why it fails**: no single promise owns the first click.
- **Repair**: choose one primary engine, one support engine, and delay the rest.

### Lore Before Pleasure

- **Symptom**: world history, rank systems, factions, and terminology arrive before the first reward.
- **Why it fails**: readers do not yet know what fun they are waiting for.
- **Repair**: move a proof scene to the opening and explain only what the scene needs.

### Passive Chosen One

- **Symptom**: protagonist has a rare class, bloodline, or system but mainly receives gifts.
- **Why it fails**: power fantasy loses competence pleasure.
- **Repair**: give the protagonist a risky choice that uses the advantage.

### Private Power-Up

- **Symptom**: stats, skills, or realm increase privately.
- **Why it fails**: no social proof or changed access.
- **Repair**: add rank board, witness, contract, duel, rescue footage, auction, or institutional response.

### Free Money

- **Symptom**: regression or future knowledge creates effortless stock/land wins.
- **Why it fails**: no suspense or earned competence.
- **Repair**: add capital limits, legal suspicion, family interference, moral cost, or changed future.

### Fake Freshness

- **Symptom**: old trope receives new names but scene path is unchanged.
- **Why it fails**: readers feel the author is hiding familiarity rather than using it.
- **Repair**: change proof object, witness, cost, institution, or timing.

### Endless Humiliation

- **Symptom**: early chapters repeatedly degrade the protagonist.
- **Why it fails**: catharsis is delayed too long.
- **Repair**: pay a small reversal quickly and let later humiliation come from stronger institutions.

### Institution Is Stupid

- **Symptom**: guild, family, sect, or association ignores obvious value only so the hero can win.
- **Why it fails**: world feels fake.
- **Repair**: make the institution rational but misaligned: measuring the wrong value, protecting incentives, hiding liability, preserving hierarchy.

### Copy Shadow

- **Symptom**: reference work's premise, rule system, opening sequence, and cast functions remain visible.
- **Why it fails**: output feels derivative and unsafe.
- **Repair**: use `originality-safety.md` and change institution, proof object, action, and consequence.

### No Serial Engine

- **Symptom**: strong episode 1, but no path after the first twist.
- **Why it fails**: the concept cannot sustain paid serialization.
- **Repair**: create personal -> institution -> region -> nation/world/system escalation.

## Repair Stack

When several failures appear, repair in this order:

1. Clarify the primary promise.
2. Build or move the first proof scene.
3. Make the protagonist's method active.
4. Add visible proof and witness.
5. Assign support genres to jobs.
6. Add cost after reward.
7. Build the 1-50 ladder.
8. Align title/logline/tags.
9. Remove copy-risk details.

## Final Sanity Line

Before finalizing, write one sentence:

`이 작품의 반복 재미는 [주인공]이 [우위]로 [기관/무대]에서 [보상]을 얻고, 그 결과 [더 큰 압박]을 여는 것이다.`

If the sentence is weak, the trope engine is not ready.
