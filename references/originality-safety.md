# Originality Safety

Use this file when the user references existing works, asks for "like X", wants to use popular cliches, or when a generated trope pack risks sounding too close to a recognizable property.

## Principle

Use genre grammar, not signature expression. It is fine to use broad devices such as gates, towers, systems, regression, sects, status windows, family succession, hidden classes, and rank tests. It is not fine to reproduce a specific work's unique names, proprietary institutions, exact rules, signature scene sequence, or distinctive character constellation.

## Abstraction Ladder

When the user names a reference:

1. Identify the **reader reward**.
2. Identify the **generic trope function**.
3. Remove specific names, terms, scene order, and unique rule phrasing.
4. Replace the institution, proof object, witness, cost, and consequence.
5. Build a new first proof scene from the generic function.

Example:

- Specific reference desire: "that feeling where the weak protagonist shocks everyone with a hidden system."
- Generic function: mismeasured protagonist becomes publicly valuable.
- New construction: an association insurance audit measures rescue liability instead of combat rank, revealing the protagonist's abnormal dungeon compatibility.

## Risk Levels

| Level | Sign | Action |
| --- | --- | --- |
| Low | broad genre device only | proceed |
| Medium | similar premise but different institution/proof | add variation axes |
| High | similar named roles, rules, and scene order | rebuild using abstraction ladder |
| Blocked | request to copy unique setting/characters/scene | refuse copying and offer a generic alternative |

## Specificity to Remove

Remove or change:

- unique organization names;
- named powers, titles, or classes associated with a specific work;
- exact tutorial/gate/floor rules;
- same opening sequence of events;
- same protagonist backstory plus same ability plus same institutional setup;
- distinctive mentor/rival/support cast functions arranged the same way;
- recognizable catchphrases or scene objects.

Keep and generalize:

- rank reversal;
- future knowledge;
- hidden condition;
- public proof;
- guild/family/sect reaction;
- revenge through evidence;
- resource mispricing;
- faction hypocrisy;
- support class undervaluation.

## Safe Transformation Checklist

Before finalizing a reference-inspired pack, check:

- Is the first proof scene newly constructed?
- Did the institution change function or behavior?
- Did the proof object change?
- Did the protagonist's advantage require a different action?
- Did the cost/consequence change?
- Are names and terms generic or newly invented?
- Could the pitch stand without mentioning the reference work?

If not, rebuild.

## Response Pattern

When a user asks for something close to a known work:

1. Acknowledge the desired pleasure in plain Korean.
2. State that the output will use the broad genre grammar, not copy unique elements.
3. Produce a transformed version with a different institution, proof object, and consequence.
4. Add a short safety note if needed.

## Copy-Risk Repair Moves

- Change hunter association into insurance regulator, labor board, disaster agency, auction house, or licensing court.
- Change tower sponsor into contract patron, divine shareholder, fan economy, treaty partner, or debt holder.
- Change hidden class into abnormal compatibility, public liability grade, forbidden technique interpretation, or production monopoly.
- Change regression harvest into altered-future management with gaps and costs.
- Change sect duel into medicine trial, honor debt hearing, escort contract, or manual ownership dispute.
- Change chaebol inheritance into creditor control, patent rights, land logistics, or shareholder proxy war.
