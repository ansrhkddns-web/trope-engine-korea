# Cliche Taxonomy Engine

Use this file to decompose any cliche into functional parts, compare cliches across genres, and rebuild them as Korean webnovel-ready trope cards.

## Cliche Unit Schema

Every cliche card should be described with these fields:

| Field | Question |
| --- | --- |
| `recognition_signal` | What makes readers immediately recognize the device? |
| `source_function` | What story function does it perform? |
| `genre_surface` | What genre skin presents it? |
| `reader_reward` | What pleasure does it pay? |
| `protagonist_action` | What does the protagonist actively do? |
| `proof_object` | What visible thing proves the result? |
| `witness` | Who must react? |
| `cost_or_taboo` | What price, rule, suspicion, or backlash renews tension? |
| `repeat_method` | How can this cliche return without feeling identical? |
| `failure_mode` | How does it become stale? |
| `freshness_axis` | What can be changed without breaking the reward? |

## Cliche Graphs

### Basic Reward Graph

`pressure -> protagonist action -> proof object -> witness reaction -> reward -> cost -> next pressure`

Use for most commercial scenes.

### Motif Relay Graph

`motif appears -> hidden function revealed -> proof object changes value -> institution reacts -> motif gains new owner/cost`

Use for items, manuals, deeds, contracts, relics, titles, and hidden floors.

### False Recognition Graph

`wrong measurement -> public dismissal -> alternate proof -> institutional correction -> new control attempt`

Use for rank tests, academy exams, guild audits, sect trials, and boardroom scenes.

### Taboo Break Graph

`rule announced -> protagonist violates or exploits it -> short-term reward -> rule owner retaliates`

Use for systems, tower floors, sect law, family rules, and contracts.

### Revenge Evidence Graph

`old wrong -> small evidence -> public venue -> proof object -> punishment -> higher sponsor revealed`

Use for revenge, chaebol, sect hypocrisy, academy bullying, and guild corruption.

### Donor Test Graph

`gatekeeper tests -> protagonist notices hidden criterion -> earns aid/title/manual/contract -> aid carries obligation`

Use for tutorials, masters, sponsors, hidden classes, and fortuitous encounters.

## Freshness Without Losing Familiarity

Preserve:

- the expected reward;
- the genre-recognition signal;
- the protagonist's active method.

Change:

- proof object;
- witness;
- institution;
- cost;
- timing;
- moral framing;
- owner of the motif;
- public consequence.

## Diagnostic Questions

Before accepting a cliche:

- Can it be staged as a scene?
- Does it give a reward before asking for patience?
- Is the proof object visible?
- Does someone powerful react?
- Can it repeat with variation?
- Does it create a next pressure?
- Is it generic genre grammar rather than a copied signature?

If not, rebuild using the graph patterns above.
